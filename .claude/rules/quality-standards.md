# 品質基準（media-agent）

**この基準は、タスクごとの完了条件へ複写しない。** レビュー（org-review）が参照する共通の基準である。
複写すると、基準が変わったときに全タスクファイルを直すことになる。

出所: `docs/design/stage0-architecture.md` 14章（T-001 / コミット e2a5b05）で定義され、
オーケストレーターが層2へ昇格させた。

---

| # | 基準 | 判定方法 |
| --- | --- | --- |
| **Q1** | 全テストが通る | `pytest` の終了コードが 0 |
| **Q2** | リント・整形に違反が無い | `ruff check .` と `ruff format --check .` の終了コードが 0 |
| **Q3** | 型チェックに違反が無い | `mypy src` の終了コードが 0 |
| **Q4** | 公開関数・メソッド・クラス属性に型注釈がある | Q3 に含まれる（`disallow_untyped_defs`） |
| **Q5** | 新規モジュールに対応する単体テストがある | `tests/unit/` の対応をレビューで確認 |
| **Q6** | 外部ネットワーク接続・認証情報の要求が無い | ネットワーク遮断 fixture（方式設計 10.4）＋レビュー |
| **Q7** | `core/` が Project 固有の事情を持たない | `src/media_agent/core/` に `.media-agent` の文字列が出現しない（grep） |
| **Q8** | 例外は `media_agent.errors` の階層を使い、終了コードへの変換は CLI 層だけで行う | レビュー |
| **Q9** | Agent は外部副作用を持たず、Action は Policy Check を経てから実行される | レビュー |
| **Q10** | ログ・監査記録に秘密値を出力しない | レビュー |

---

## 由来

| 基準 | 根拠 |
| --- | --- |
| Q6 | PO 制約 C-1 / C-2（X へ投稿しない・認証情報を環境に置かない）。**Stage 0 の間は目視ではなくテストで担保する** |
| Q7 | 要件定義書 20.2（保守性）・開発原則6「Project固有情報をCoreに混ぜない」 |
| Q8 | 方式設計 6.5。CLI 層を唯一の例外変換点にする。CLI 側に `isinstance` の分岐表を作らない |
| Q9 | 要件定義書 2.4「DecisionとActionを分離」・開発原則5 |
| Q10 | 要件定義書 14.2（Credential を漏らさない） |

## 適用範囲

- Q1〜Q5 は Stage 0 以降ずっと有効
- **Q6 は Stage 0 と、外部接続を実装しない全 Stage で有効。** Stage 3（X Publisher）以降で
  外部接続を実装する際は、この基準そのものを改訂すること。改訂せずに例外を作らない

# タスク台帳の読み方

このディレクトリは**タスク別の詳細ファイル**を置く場所である。索引は
`docs/task-list-media-agent.csv`（リポジトリルート直下の `docs/`）にある。

## どこから読むか

1. `docs/handover.md` — ゴールと達成条件、直近のセッションで何が起きたか
2. `docs/task-list-media-agent.csv` — 全タスクの索引（状態・担当・依存）
3. `docs/tasks/T-XXX.md` — 触るタスクの詳細だけ

**索引の全件を読んでから詳細へ降りること。** 詳細ファイルを最初から順に読む
必要は無い。分けてあるのは、1つのタスクを触るセッションが、完了済み全タスクの
証拠まで読み込まずに済むようにするためである。

## タスク別ファイルは、そのまま作業指示である

`docs/tasks/T-XXX.md` に書かれていることが、担当エージェントへの指示の全文である。
作業指示は別途書き下ろされない。**セクションが空であることが、指示の抜けを可視化する。**

着手前に、次の4つが埋まっているか確認する。欠けていればオーケストレーターへ差し戻す。

1. 完了条件
2. 判断してよい範囲
3. 参照すべき成果物が実在するか
4. 目的と詳細から、何をすべきかが一意に定まるか

## 誰が何を書くか

| 対象 | 書く主体 |
| --- | --- |
| `docs/task-list-media-agent.csv` | オーケストレーターだけ |
| `T-XXX.md` の 決定ログ / 作業ログ / 証拠 / 進捗 | 担当エージェント（自分のタスクのファイルだけ） |
| `T-XXX.md` の 状態 / 担当 / 依存 / 優先度 | オーケストレーター |

書式の規約は `.claude/rules/org-task-ledger.md` にある。

## 検査

```sh
python3 .claude/scripts/org-check.py
```

索引と詳細ファイルの食い違い、空欄、定義外の状態、停滞候補を機械的に検出する。

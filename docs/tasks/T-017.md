## 補完すべき2件

### RV-8: `logs/media-agent.log` がディレクトリのときの扱い

`src/media_agent/cli/session.py:110`（`setup_cli_logging`）／`src/media_agent/cli/diagnostics.py:576`（検査10）。

**`.media-agent/logs/media-agent.log` が「ディレクトリ」のとき、`status` / `run` / `task list` が終了コード 70 になる**
（`IsADirectoryError` が包まれない）。**同じ状態で `doctor` は 0 を返す。**

詳細設計 7.3 が名指しで却下した「doctor は通るのに 70」という形が、この1経路だけ残っている。

**実装は設計に違反していない。** 17.4.1 が構造破損の対象を「4ディレクトリ + `db_path`」の
**閉じた集合**と定義しており、実装はそれを漏れなく実装している。さらに **D-X7 が
「その他の環境異常は 70 になりうる。Stage 3 で見直す」と明示的に受け入れている。**

**Major にしなかった理由（T-009 の判定。踏襲すること）**: RV-1 が Major だったのは
**利用者がツール自身の助言に従って行き止まりに入る**ためである。**RV-8 に助言は存在しない。**
stderr に絶対パスと `Is a directory` が出るため復旧できる。

決めること:

1. **D-X7 の残余の列挙へ、この経路を明示的に加えるか**（T-009 の推奨はこれ）
2. 加えるなら、Stage 3 で見直す際の条件に何を書くか
3. **加えない**と決めるなら、その理由（`doctor` が 0 を返すことを許容する根拠）

### RV-9: `db_path` がディレクトリのときの文面

`src/media_agent/project/layout.py:113-118` ／ 詳細設計 17.3・17.4.3。

**17.4.1 は種別1 に「またはその逆」（ファイルであるべきパスがディレクトリ）を含めているが、
17.3 / 17.4.3 の安定文字列表に逆向きの行が無い。** 規範は「ディレクトリではありません」の1文面だけである。

T-014 は `... は通常のファイルではありません` を実装した。**対象は現にディレクトリなので、
「ディレクトリではありません」は事実に反する。実装側が正しい。**

決めること: 17.3 / 17.4.3 へ逆向きの行を足す。**実装が既に出している文面に合わせること**
（文面を変えると受け入れテストが落ちる。**それは設計の都合でテストを壊すことになる**）。

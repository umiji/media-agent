## 並列実行についての判断（2026-08-23）

実装タスク T-004〜T-007 は、モジュールとしては互いに独立しており並列に走らせられる。
**それでも直列にした。** 同一ワークツリーで複数の実装エージェントが同時に `git add` / `git commit` すると
インデックスが競合して壊れるため。並列化の利得より、壊れた作業ツリーの復旧コストが大きい。

並列に走らせるのは、ワークツリーへの書き込みが衝突しない組み合わせだけ:

- T-009（レビュー・読み取りのみ）と T-010（`docs/` 配下のみ）
